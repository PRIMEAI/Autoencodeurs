VQ-VAE : un espace latent discret

Moulay Akhloufi

Dans un VQ-VAE (van den Oord et al. 2017), la sortie de l’encodeur ze(x) est remplacée par le vecteur le plus proche d’un dictionnaire {e1, …, eK} appris. Le décodeur ne voit que zq(x) = ek : chaque position de l’image devient un indice entier k, comme un mot d’un vocabulaire. Ici en 2D : déplacez le point orange ou les vecteurs du dictionnaire.

À retenir

zq(x) = ek avec k = argminj ‖ze(x) − ej‖. L’argmin n’est pas dérivable : on recopie le gradient de zq vers ze (straight-through estimator).
Perte : ‖x − x̂‖² + ‖sg[ze] − e‖² + β ‖ze − sg[e]‖² (sg = arrêt du gradient). Le 2e terme rapproche les vecteurs du dictionnaire des sorties de l’encodeur (comme k-moyennes, ce que fait le bouton « Mettre à jour ») ; le 3e (engagement) empêche l’encodeur de s’éloigner du dictionnaire.
Les codes discrets se prêtent bien à un modèle autorégressif (PixelCNN, transformeur) qui apprend la loi a priori sur les indices. C’est aussi le principe des « tokens » d’image de nombreux générateurs (VQ-GAN, DALL·E 1). Un vecteur jamais choisi est un code « mort ».
